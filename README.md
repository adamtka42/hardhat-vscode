# Hyperion for Visual Studio Code

**Hyperion for VS Code** is a [Visual Studio Code](https://code.visualstudio.com/) extension that provides enhanced [Hyperion language](https://github.com/theqrl/hyperion) features for smart contract development on the [QRL](https://www.theqrl.org/) Zond network.

Based on [hardhat-vscode](https://github.com/NomicFoundation/hardhat-vscode) by the Nomic Foundation, ported to Hyperion for the QRL/Zond ecosystem.

## Packages

Please refer to one of these packages to find detailed documentation relevant to your use case:

- [Hyperion language server](./server/README.md)
- [VSCode extension](./client/README.md)
- [coc.nvim extension](./coc/README.md)
